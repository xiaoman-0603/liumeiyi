var wySw4 = new Swiper("#wySw4", {

Q1：你的第一版提示词漏掉了哪个需求？

Q3：AI 第一次给的代码错在哪？
错在 effect 用了 "slide"，与“初始效果为 cube”不符；另外我第一版提示词把选择器写成了小写 #wysw4，真实 id 是 wySw4（大小写敏感），AI 回答里帮我把大小写纠正回了 #wySw4。

任务二 · creative 仿写第 7 种效果 · 电影选片墙 · prev / next 追问

参考 swiper/demo/257-effect-creative.html 的第一个示例，在演示四新增第 7 个按钮 creative 电影墙：上一张向屏幕深处后退并缩小（透视 + 阴影），下一张从右侧滑入。　现场演示：swiper-task.html · 演示四

我给 AI 的追问 已实现

参考 257-effect-creative 第一个示例的 creativeEffect 写法，加第 7 种效果；再用大白话解释：prev / next 的 transform 各控制什么？
AI 给出的核心配置
creativeEffect: {
  prev: {
    shadow: true,
    translate: [0, 0, -400],    // 向屏幕里后退 400px
  },
  next: {
    translate: ["100%", 0, 0], // 停在右侧一屏宽处
  },
},
用自己的话解释

prev 控制“已经滑走的上一张”：translate 是 [X, Y, Z]，这里 Z 为 -400，表示往屏幕里面退 400px，有透视时看起来就变小了；shadow 给它补一层阴影，层次更像一叠卡片。next 控制“还没进来的下一张”：X 为 "100%"，按自身宽度算，等于把它放在右侧一整个 slide 宽的位置，滑进来时再线性回到 0。

答辩抽问

Q1：transform 里的百分数是相对谁的？
相对幻灯片自己。Swiper 把这些字符串直接拼进 CSS 的 translate3d()，百分比位移按元素自身尺寸计算：X 相对 slide 自身宽度，Y 相对自身高度，不是相对视口或轮播容器。所以 next 的 "100%" 就是一张 slide 的宽度。
Q2：改一个数值让卡片转 20 度试试？
在 prev 里加一行 rotate: [0, 20, 0]（第二个值是绕 Y 轴的角度），上一张离场时就会转 20°；想更夸张可临时改成 45 再切回 20。

第 1 轮 · 加第六件展品 + zoom 已实现

我的提示词
照片我已经生成好了 d:/网页制作/首艘国产大型邮轮.png。挑选此html没有运用过的swiper能力。
AI 给出的代码
var lmySw5 = new Swiper("#lmySw5", {
  loop: true,
  speed: 700,
  initialSlide: 5,        // 打开页面先显示“爱达·魔都号”
  autoplay: {
    delay: 4000,          // 每 4 秒自动翻页
    disableOnInteraction: false,
  },
  pagination: {
    el: "#lmyPag5",      // 当时还配了圆点分页器（第 2 轮才删）
    clickable: true,
  },
  zoom: {
    maxRatio: 3,          // 最多放大 3 倍
    toggle: true,         // 双击放大，再双击还原
  },
});
说明：AI 在本页没用过的能力里选了 zoom；图片必须包进 .swiper-zoom-container 才能双击缩放（照官方 400-zoom.html 示例的结构）。验证时还踩过一个真实的坑：自动化模拟的双击事件没触发 zoom，最后用临时测试页调用 zoom.in() API 确认配置正确——真实浏览器里双击有效。
第 1 轮一句话结论：第六件展品「爱达·魔都号」上线，双击放大 3 倍、再双击还原，圆点和自动播放照常工作。

第 2 轮 · 按示例换掉圆点 已实现

我的提示词
根据 d:/网页制作/swiper/demo 下的示例，使用 swiper-task.html 中没有运用过的效果，把第六件展品的演示效果也做改变。比如不要圆点选择器、平移切换。但是当前的 zoom 效果需要保留。
AI 修改的配置（删 + 增）
pagination: { el: "#lmyPag5", ... },  // 删：圆点分页器整个去掉

grabCursor: true,                  // 增：抓手光标（190-grab-cursor）
keyboard: {
  enabled: true,                   // 增：方向键切换（260-keyboard-control）
},
scrollbar: {
  el: "#lmySb5",                   // 增：滚动条替代圆点（080-scrollbar）
  draggable: true,                // 滚动条可拖动换片
  hide: false,
},
zoom: { maxRatio: 3, toggle: true }, // zoom 原样保留
同步改动：HTML 删掉 #lmyPag5，在轮播容器外新增 <div class="swiper-scrollbar" id="lmySb5">，滚动条另加了配色。浏览器实测：圆点消失、滚动条带拖拽块、按 ArrowRight 时 activeIndex 4→5 切换成功、zoom 配置未动。
第 2 轮一句话结论：演示五改为「滚动条拖动 + 键盘方向键」切换，圆点移除，zoom 双击缩放完整保留。

答辩四问

Q1：这段代码什么意思？
loop 循环播放；autoplay.delay 每 4 秒翻一张，disableOnInteraction: false 让手动操作后继续；scrollbar.el 绑定滚动条元素、draggable: true 允许按住滚动条拖动换片；keyboard.enabled 打开 ←/→ 方向键切换；zoom.maxRatio 限制最大放大 3 倍，toggle 让双击在放大与还原之间切换。
Q2：为什么图片必须包在 .swiper-zoom-container 里？
zoom 模块把双击监听和缩放 transform 绑定在 .swiper-zoom-container 上，图片直接放在 slide 里时这个容器不存在，双击就没有任何反应；这是官方 400-zoom.html 示例规定的结构。
Q3：第 2 轮新增参数的作用？
scrollbar.draggable 让滚动条可以拖拽到任意进度直接跳片；hide: false 让滚动条常显不自动隐藏；keyboard.enabled 在轮播位于视口内时支持方向键；grabCursor 只改光标样式，提示“可抓取”。
Q4：现场把 delay 改成指定值并解释预期变化？
把 delay: 4000 改成 2000：每张停留时间减半，自动翻页变快；改成 6000 则变慢。只要 disableOnInteraction: false 不变，手动操作后仍会继续自动播放。
